# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录执行 `npm start` 起本地静态服务访问（默认 http://localhost:8000）。

## npm 脚本（Node ≥ 18，零运行时依赖）

| 命令 | 作用 |
| --- | --- |
| `npm start` | 启动零依赖本地静态服务（`PORT=3000 npm start` 可改端口，`HOST` 可改监听地址） |
| `npm test` | 运行回归测试（`test/regression.js`），退出码 0/1 |
| `npm run check` | 对全部 JS 做 `node --check` 语法检查 |
| `npm run install-hooks` | 安装 Git 提交前检查钩子 |

`npm install` 时会经 `prepare` 自动安装提交前检查钩子（非 git 环境安静跳过）。

## 提交前检查

`.git/hooks/pre-commit`（源文件 `scripts/pre-commit`）在提交前依次执行 `npm run check` 与 `npm test`，任一不通过即中止提交；需要绕过用 `git commit --no-verify`。

## 多项目与多版面

- 顶部管理栏可新建、切换、重命名、移除项目；每个项目下可新建、切换、重命名、移除多个版面。
- 字模库、落字、草稿与版面设置（纸张、方向、网格、作品名）均按版面分别保存，项目与版面之间互不串数据。
- 至少保留一个项目；每个项目至少保留一个版面（最后一个项目/版面的「移除」按钮会禁用）。
- 移除项目或版面前会弹出确认；切换不会清空任何未保存内容，所有改动即时写入浏览器本地存储。
- 刷新页面后，项目、版面、字模、落字、草稿与设置都会恢复；旧版单项目数据会在首次打开时自动迁移为「项目1 / 默认版面」。

## 备份与恢复

- 顶部「导出备份」把**全部项目**及其版面、字模库、落字、草稿和设置（含当前所在项目）导出为一个带类型标记与时间戳的 JSON 文件（如 `活字排版工坊-备份-2026-09-12-153000.json`）。
- 「导入备份」选择 JSON 后，会先提示备份中的项目/版面/字模规模并要求确认；**确认后覆盖当前全部数据**（不可撤销），取消则数据不动。
- 导入成功即时写入本地存储，刷新页面后与恢复结果一致；恢复后项目与版面的新建、切换、重命名、移除照常可用。
- 文件不是合法 JSON、不是本工坊备份、或缺少项目/版面/字模/落字/草稿/设置等必要数据时，会弹出具体的「导入失败」原因，当前数据与本地存储均不改动。

## 回归测试

```bash
npm test          # 等价于 node test/regression.js
```

只用 Node 内置模块（在 `vm` 沙箱中桩掉 localStorage、DOM 与弹窗），不依赖浏览器、点击页面或外部服务；通过退出码反映结果（0 通过，1 有失败），可直接放进 CI 或 pre-commit。

覆盖范围：

- 项目与版面的新建、切换、重命名、移除（含确认框取消与确认两条路径）；
- 至少保留一个项目、每个项目至少保留一个版面（最后一个不可移除）；
- 项目之间、同项目的版面之间，字模库、落字、草稿与设置互不串数据（含存储层对象引用独立性检查）；
- 切换/移除不清空未保存内容；
- 复用同一份 localStorage 重新加载（模拟刷新），项目、版面、字模、落字、草稿与设置全部保留；
- 备份导出（全量、深拷贝、触发 JSON 下载）与导入恢复（确认才覆盖、取消不动、导入后刷新一致、九类损坏/缺字段文件明确报错且不改数据）；
- 旧版 v1 单项目数据迁移（含空字模库、畸形条目、非法设置、损坏 JSON 等边界）。
