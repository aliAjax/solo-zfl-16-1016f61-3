# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 多项目与多版面

- 顶部管理栏可新建、切换、重命名、移除项目；每个项目下可新建、切换、重命名、移除多个版面。
- 字模库、落字、草稿与版面设置（纸张、方向、网格、作品名）均按版面分别保存，项目与版面之间互不串数据。
- 至少保留一个项目；每个项目至少保留一个版面（最后一个项目/版面的「移除」按钮会禁用）。
- 移除项目或版面前会弹出确认；切换不会清空任何未保存内容，所有改动即时写入浏览器本地存储。
- 刷新页面后，项目、版面、字模、落字、草稿与设置都会恢复；旧版单项目数据会在首次打开时自动迁移为「项目1 / 默认版面」。
